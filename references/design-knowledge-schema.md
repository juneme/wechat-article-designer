# Design Knowledge Schema

Use this schema when learning a design source or updating the living grammar. A source item is evidence for reusable decisions, never a complete article template.

## Normalized source record

Record one entry per source item:

| Field | Meaning |
|---|---|
| `identity` | Stable slug, URL, or source identifier |
| `title` | Source title for provenance |
| `source_type` | Landing page, editorial page, dashboard, interaction, component, or other |
| `observed_at` | Study date and available source update time |
| `content_fit` | Readers, content types, risk profiles, and evidence conditions that fit |
| `visual_thesis` | One sentence describing the governing relationship |
| `palette` | Field, ink, accent, correction, contrast, and image authority |
| `typography` | Display/body/label/data relationships, density, and line behavior |
| `composition` | Opening, section rhythm, alignment, massing, density curve, and close |
| `geometry` | Edge language, surfaces, rules, radii, and recurring shapes |
| `media` | Image roles, ratios, crops, captions, and sequence |
| `interaction` | Reveal, motion, hover, drag, or sticky behavior in the source |
| `static_translation` | How interaction becomes complete single-column WeChat reading |
| `evidence_boundary` | Claims or contexts where the treatment should not be reused |
| `new_contribution` | New grammar rule, stronger evidence, counterexample, or no change |

Keep observations literal. Separate what the source visibly does from the design decision inferred from it.

## Capability test

Before merging a source contribution, answer:

1. What reader or content problem does this decision solve?
2. Is it already represented in the living grammar?
3. Which part is a transferable relationship rather than source branding?
4. What survives without scripts, custom fonts, hover, motion, sticky state, or desktop width?
5. What evidence or risk boundary limits its use?
6. Can it combine with other grammar dimensions without reproducing the source page?

Merge only the useful answer. Source names belong in the dated study and record index, not in the normal generation route.

## Aggregated grammar dimensions

Update the grammar through these dimensions:

- visual field and color roles;
- type hierarchy and Chinese reading behavior;
- opening and closing mechanisms;
- module order, alignment, width, and density curve;
- geometry and surface language;
- media roles and narrative sequence;
- static translation of interaction;
- evidence, audience, and risk boundaries.

Counts describe study coverage only. They never define the number of templates, styles, or outputs the skill can create.

## Provenance requirements

A dated study snapshot records scope, collection method, limitations, observed totals, and aggregate findings. A record index accounts for every current public item with stable identity, date, normalized signals, and contribution. Later refreshes compare stable identities and source update times, then recompute aggregate findings across the complete current corpus.
